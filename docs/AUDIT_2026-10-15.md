## Applicable model scope

Actual source is a deterministic expected-value engine with an already isolated
`random.Random(seed)` synthetic generator. There is no global PRNG mutation,
Monte Carlo loop, correlation matrix, VaR or expected-shortfall implementation.
Adding such estimators, a NumPy dependency or invented confidence intervals would
change the model rather than repair the inspected code. The new tests verify
existing PD/LGD/EAD domains, ultimate-loss/accounting identities and reproducibility.
The [model-risk record](MODEL_RISK.md) documents the legacy SR 11-7 crosswalk,
current primary guidance, empirical-validation limits and governance requirements.
